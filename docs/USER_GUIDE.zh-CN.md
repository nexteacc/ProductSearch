# 商品研究 0.1.1 本地交付版

## 安装与准备

本包提供 macOS Intel x64 的 ProductResearch.app，不需要安装 Node 或 Codex。Apple Silicon、Windows 和 Linux 尚未验收，不作为本包的支持承诺。

解压后将 ProductResearch.app 放入“应用程序”目录，再双击启动。本包尚未签名和公证，适用于受控测试交付。遇到 macOS 安全阻止时，请核实来源并按系统提供的批准方式处理，不要关闭系统安全保护。

外部依赖是 Ego Lite 浏览器及其官方 ego-browser 命令，请按官方说明安装、启动。浏览器和登录状态不包含在安装包中。

首次启动会在当前电脑、当前用户的应用数据目录创建独立空间。不包含交付者的密钥、登录态、设置、历史任务、采集结果或日志。

## 首次配置

1. 设置 → 浏览器连接 → 检查连接。路径默认自动查找，找不到时在“高级”填写本机 ego-browser 路径。
2. 如果要自动判断，在“自动判断”中保存自己的 TypeSafe API Key；只采集可关闭自动判断，不需要 Key。
3. 保存设置。密钥加密保存，不回显；换电脑需重新配置，不复制他人的加密文件。

应用检查本地存储是否可写、浏览器是否连接、判断密钥是否可解密。“环境就绪”不代表 API Key 已通过远端验证，也不代表三个网站都已登录。

## 工作台与任务记录

新建任务填写研究主题、搜索关键词、平台和数量。每个平台默认 150 条，允许 1–500 条。执行预算随数量调整；网站实际返回数量可能不足，应用如实显示实际数量和停止原因。

首版采集 Amazon.com、Etsy 美国/USD 和 Pinterest.com。域名或币种不等于已确认美国配送地址，请在自己的浏览器中确认地区和登录状态。

开启判断：显示推荐名单，默认 ≥80%，可切 ≥90%。推荐分是纳入主题候选的判断概率，不代表销量、热度或商品质量。

关闭判断：按采集顺序显示全部记录，标记“未判断”，不生成推荐分。已采集数据可通过“判断这批数据”单独判断，不重新采集。

执行过程保留数量、停止原因、批次、耗时和错误提示。没有回放和导出功能。任务记录保存每次独立运行。

## 错误与恢复

- 浏览器未连接：打开 Ego Lite，在设置中检查连接。
- 未登录或平台要求验证：在浏览器中正常处理，应用不绕过验证，不自动重复尝试。
- 数量不足：查看平台停止原因，已有结果保留。
- Key 无效、限流或判断失败：采集记录保留；没有判断结果时展示未判断名单，修正后可补做判断。
- 磁盘空间或权限问题：处理后重启，不删除数据目录。
- 个别任务记录损坏：隔离提示并保留原文件，其余可读任务仍可使用。
- 取消或异常退出：已保存部分保留，重启后标记中断，不静默重跑。

关闭窗口只隐藏应用，后台任务继续；⌘Q 完全退出会请求取消任务并关闭本地服务。

## 本地 MCP

安全限制：最多 5 个待执行任务；按本机日期每日最多新增 20 个任务、150 批模型请求和 1,500 条判断记录。应用界面和 MCP 共用额度，重启不清零，失败请求也计数；这些是调用量限制，不是金额承诺。取消任务不退还已占用任务次数。额度文件损坏或日期回退时停止新增调用，保留数据。浏览器子进程仅接收必要环境变量，不继承 API Key 或其他服务凭证。

安装包分别提供 arm64（Apple Silicon）和 x64（Intel）。架构和实际测试范围以交付报告为准。当前未进行开发者签名、公证，不能宣称已获得 Apple 安全认证。配置新密钥前，请在服务商后台撤销曾公开的旧密钥；复制应用不迁移个人密钥或浏览器登录态。

设置 → 本地 MCP → 复制配置，添加到同机 MCP 客户端。应用须保持启动；安装位置改变后重新复制配置。不在 MCP 配置中填写 TypeSafe Key。

提供创建、列表、详情与结果、取消、判断已有数据五个工具。创建任务立即返回编号，后续用 get_research_task 查询状态；includeResults=true 时附带名单，threshold 可选 0.8 或 0.9，offset 和 limit 控制分页。执行时内部检查所需环境，不暴露密钥管理功能。只监听本机；不分享应用数据目录或 connection.json，不提供远程 SaaS。

名单默认每页 40 条，最多 100 条。filters 支持 platforms、titleContains、titleExcludes、ratingAbove（严格大于，缺失或无法明确解析的不匹配）、hasFields（priceText、ratingText、boughtText、imageUrl、url）。先筛选再分页，返回 originalTotal、total、完整 items、hasMore、nextOffset 和 appliedFilters。未判断名单不附分数、不使用推荐分阈值。建议任务完成后再连续分页，避免运行中的名单变化。默认不返回日志；includeEvents=true 时返回最近 eventLimit 条，默认 20、最多 100 条。

例如：在 Pinterest 搜索 polka dot tote bag，采集 150 条，关闭自动判断。取得任务编号后查询状态，完成后附带前 40 条结果。创建任务时复用相同 requestId 可避免重复提交；判断已有数据会创建新判断任务，请勿盲目重复调用。

## 本版边界

交付的是本地采集与可选判断链路，不含每日定时、云浏览器或跨设备同步。空数据空间启动和程序测试不等于另一台物理电脑验收，也不保证网站未来结构不变。接收方首次建议小样本测试，再逐步提高采集量。
